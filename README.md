# Modern Redux Toolkit demo (React Native)

React Native demo of Redux Toolkit.

## What it contains

- `src/app/store.js`: the store
- `src/features/counter/counter-slice.js`: a counter slice
- `src/features/dogs/dogs-api-slice.js`: an RTK Query API slice for [The Dog API](https://thedogapi.com) (`https://api.thedogapi.com/v1`)
- `src/Main.js`: the screen with the counter buttons and a list of dog breeds (`useFetchBreedsQuery`)

## Stack

React Native 0.66.1, React 17.0.2, `@reduxjs/toolkit` 1.6.2, `react-redux` 7.2.6.

## Run

1. Get a free API key from thedogapi.com and put it in the `DOGS_API_KEY` constant in
   `src/features/dogs/dogs-api-slice.js`. No key is stored in this repository.
2. Then:

```sh
npm install
npx react-native run-android   # or run-ios
```
